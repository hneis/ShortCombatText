# ShortCombatText

Минимальный аддон для WoW Forever, который заменяет локализованные подписи
боевого текста английскими вариантами: `Miss`, `Dodge`, `Parry`, `Block`,
`Absorb`, `Resist` и другими.

## Совместимость

- WoW Forever Beta `1.60.1.70338`;
- Interface `16001`;
- Lua 5.1;
- без зависимостей и SavedVariables.

## Как работает

Аддон переопределяет используемые Blizzard глобальные строки при загрузке,
входе персонажа и появлении в мире. Несколько коротких отложенных повторов
нужны на случай, если load-on-demand модули Blizzard позднее восстановят
локализованные значения.

Кроме результатов попадания, переводятся системные сообщения `Health Low`,
`Mana Low`, вход и выход из боя, окончание ауры, честь, комбо-очки, руна и все
пять предупреждений угрозы (`High Threat`, `Attacking You!`, `Losing Threat`
и `Changed Target!`). Native-подпись полученного опыта отображается как
`XP:123`, а текст XP-панели как `XP:123/456`. Остальные значения соответствуют
enUS Blizzard; форматные маркеры `%s`, `%d` и `|4` сохранены.

Реактивное сообщение `<Ответный удар>` приходит не из глобальной строки, а как
локализованное имя способности. После загрузки `Blizzard_CombatText` аддон
точечно заменяет его на `<Riposte>`. Если клиент помечает готовое сообщение как
secret value, оно передаётся Blizzard без сравнения и изменения.

Изменения действуют на весь интерфейс до перезагрузки UI и могут затрагивать
любые Blizzard-фреймы или другие аддоны, использующие те же глобальные строки.

## NiceDamage

Аддоны дополняют друг друга и не зависят друг от друга:

- NiceDamage меняет `DAMAGE_TEXT_FONT` и, при включённой опции, шрифт scrolling
  combat text;
- ShortCombatText меняет только содержимое подписей;
- регистр остаётся исходным enUS (`Riposte`, а не `RIPOSTE`).

В NiceDamage включите **Scrolling Combat Text**, если его шрифт должен
применяться и к сообщениям над персонажем.

## Команды

- `/sctfix` повторно применяет короткие подписи;
- `/sctdebug` выводит текущие строки блокирования и угрозы, а также состояние
  обработчика Riposte.

## Установка

Для GitAddonsManager добавьте публичный HTTPS-адрес репозитория:

```text
https://github.com/hneis/ShortCombatText.git
```

Итоговый путь должен быть таким:

```text
<WoW>\_classic_beta_\Interface\AddOns\ShortCombatText\ShortCombatText.toc
```

Для ручной установки скопируйте каталог `ShortCombatText` в папку `AddOns`,
затем перезапустите игру или выполните `/reload`.

## Разработка

Из корня репозитория:

```bash
./tools/validate.sh
lua5.1 tests/test_short_combat_text.lua
```

Валидатор проверяет Lua 5.1, Interface, версию и пути из основного TOC. Mock-тест
проверяет точные enUS-строки, события загрузки, отложенное повторное применение,
secret-safe обработку Riposte и slash-команды. Финальную проверку визуального
combat text необходимо выполнять в клиенте Forever Beta.
